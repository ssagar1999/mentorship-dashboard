A PR comment or review from an OWNER, MEMBER or COLLABORATOR. Bots and CI are excluded — “only bot/CI comments” is stated explicitly rather than counted as a human reply.

Student activity

PR created, commits pushed to the PR, PR comments, and public push/PR events on the account.

Waiting days

Measured from whoever owes the next step: the student when changes are requested, otherwise the maintainer's silence (last reply, or PR opening if there was never one). Students are never penalised for a maintainer's delay.

Status precedence

Changes requested → inactive (silent 7+ days) → stuck (10+ days) → follow-up (6–9) → waiting (3–5) → in review → active. Merged and closed PRs are outcomes, never pending work.

Known gaps

No assigned issues, no program repo and no mentor notes were supplied, so “no PR” can also mean “working privately”. Three handles don't resolve on GitHub and are flagged individually. Only the 10 most recent PRs per student are examined.

Not collected

CI status and merge conflicts. If they are not in this dashboard, nobody has claimed they are blocking.
